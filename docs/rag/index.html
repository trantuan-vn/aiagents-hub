KRX.DR · Workflow sinh SQL đa hệ CSDL

Sinh câu SQL trả số liệu từ một chức năng trên ứng dụng — cho mọi loại database

Workflow này cho phép bấm đúng một chức năng trên ứng dụng, bắt lại toàn bộ câu lệnh mà database vừa thực thi, chọn ra câu trả số liệu, lấy giá trị tham số, kiểm chứng với màn hình, rồi lưu thành một cặp “Yêu cầu số liệu – SQL” có định danh. Hỗ trợ Oracle, PostgreSQL, MySQL, SQL Server, IBM Db2 và MongoDB.

  7. Lưu thành cặp

Workflow trực quan

Workflow được xây dựng trên nền tảng AI Agents Hub, mỗi node đảm nhận một bước: nhận yêu cầu, sinh SQL, kiểm tra SQL, lấy bind, lưu cặp. Toàn bộ luồng chạy tự động, người dùng chỉ cần chọn chức năng và xác nhận kết quả.

Ảnh 1 — Sơ đồ workflow. Luồng node từ Chat Message Received → Researching Agent → Check SQL → Get Bind → Save SQL Pair. Mỗi node có nhiệm vụ riêng và có thể chạy lại độc lập.
Ảnh 2 — Workflow được chia sẻ. Workflow KRX.DR.v1.1 đã được publish ở chế độ Community Sharing, sẵn sàng cho người khác xem, chạy và đánh giá.
Điểm mạnh của workflow

Tách rời từng bước, có thể kiểm tra và chạy lại một phần. Kết quả được lưu thành cặp có định danh, dùng lại được cho nhiều môi trường database khác nhau.

Chọn database để xem hướng dẫn chi tiết

Mỗi tài liệu dưới đây mô tả đầy đủ 11 bước lọc cặp “Yêu cầu số liệu – SQL”, kèm câu lệnh cụ thể cho từng hệ quản trị. Bấm vào một database để mở hướng dẫn tương ứng.

Relational (SQL)

O

Oracle

Dùng V$SQL, V$SQL_BIND_CAPTURE, trace file để bắt SQL và bind.

Relational

Relational

Relational
S

SQL Server

Dùng DMV (sys.dm_exec_query_stats) và Extended Events để bắt bind.

Relational
D

IBM Db2

Dùng monitor function MON_GET_PKG_CACHE_STMT và Event Monitor.

Relational

NoSQL

Mg

Chuẩn bị Database mẫu

Quy tắc phủ đủ giá trị cho mọi cột và viết comment chuyên ngành đầy đủ cho từng cột.

Bắt buộc
Thứ tự thực hiện khuyến nghị

1) Chuẩn bị database mẫu đúng chuẩn. 2) Chọn hướng dẫn theo database đang dùng. 3) Chạy đủ 11 bước. 4) Lưu cặp vào hệ thống quản lý yêu cầu số liệu.

Cách dùng bộ tài liệu

  • Bước 1 — Chuẩn bị: mở Chuẩn bị Database mẫu để đảm bảo dữ liệu đủ giá trị và mọi cột đều có comment.
  • Bước 2 — Chọn database: mở đúng tài liệu theo hệ quản trị đang dùng (Oracle, PostgreSQL, MySQL, SQL Server, IBM Db2 hoặc MongoDB).
  • Bước 3 — Thực hiện 11 bước: làm theo thứ tự, đánh dấu vào ô “Đã hoàn thành” để theo dõi tiến độ.
  • Bước 4 — Lưu cặp: dùng bảng “Lưu thành cặp thông tin” ở bước 11 để ghi lại mã yêu cầu, SQL, tham số và kết quả đối chiếu.
Mẹo

Mỗi tài liệu đều có nút “Sao chép” cho từng câu lệnh. Bấm để copy nhanh, không cần chọn thủ công.
